# Borç ve Emanet Takip Uygulaması

Java ve SQLite kullanılarak geliştirilen Android tabanlı borç ve emanet takip uygulaması.

## Kullanılan Teknolojiler
- Java
- SQLite
- Android Studio
- RecyclerView
- DAO Architecture

## Özellikler
- Borç ve emanet kayıt yönetimi
- Dinamik form yapıları
- SQLite veritabanı entegrasyonu
- Kullanıcı odaklı mobil arayüz
- Veri bütünlüğü yönetimi

## Proje Durumu
Proje geliştirme aşamasındadır.

## Amaç
Mobil platformlarda kullanıcı dostu veri yönetimi ve dinamik kayıt sistemleri geliştirmek.
